# p2 V3 — 同一篇貓 CEO 貼文裡學會單字

## V2 結構判斷（實作前）

依 p2 / p2-v2 JSON、VideoTemplate、Feed / FeedItems、Mascot、設計規範與 V2 render 檢查：

1. Feed 上滑掩蓋不了「post → card → post → card」的內容重置。白卡成為獨立教材，原句只剩邊緣的淡字。
2. 單字、意思、例句依序登場，觀眾等待下一個資訊；大字與外框本身成為主角。
3. 略過 CFO 問原因、貓把筆撥掉的段落，留下兩個教學載體，失去社群內容的笑點與因果。
4. 深色 quiz、置中選項與白底貼文不同，像切進另一個產品。
5. 豆腐在最後字卡、回顧、測驗、結尾長時間共用固定位置；沒有持續的敘事任務，且部分畫面下方空白只是容納角色。

## V3 attention flow

| 時間 | 同一篇內容中的變化 | 注意力與動作理由 |
|---|---|---|
| 0–1.9 | 作者、90% 預算比例、紙箱反差 | 0.3–0.65 秒紙箱從弱化到全亮；比例條具體呈現九成，第一秒完成反差 |
| 1.9–5.4 | 往下讀原句，allocate 仍在句中 | 鏡頭沿同一欄上移，沒有換頁 |
| 5.4–12.1 | 原句下方打開 allocate 解釋 | 黃色標记、相連的左線、向下擴張形成因果；意思／詞性／完整例句／翻譯一起展開 |
| 12.1–16.9 | 解釋收回；CFO 問原因，貓撥掉筆 | 下方正文隨 reflow 補位，還是同一篇貼文 |
| 16.9–19 | 決定 final，且 completely arbitrary | 不需要新作者或新場景 |
| 19–24.7 | arbitrary 原句下方展開 | 同樣的局部解釋方式，完整保留例句與翻譯 |
| 24.7–29 | 收回解釋、散會、讀留言回想 | 紙色、貼文邊線、正文延續；兩選項考意思，避免只憑詞性猜答案 |
| 29–31.5 | 留言填回 arbitrary，黃色正解 | 回饋連結 allocate 預算與 arbitrary 決定，直接在內容中結束 |

沒有獨立 recap、logo、下一篇預告。英文來源與例句沿用 p2；「散會。理由？貓說了算。」是編輯反應文案。

## Review 與限制

以整段時間軸、轉場抽幀與 360×640 檢查觀看流。單字解釋開啟時原句完整可見；沒有全頁淡出或深色測驗；豆腐僅服務首秒反差。首輪檢查發現「蛤？」與豆腐帽子太近，修正為角色右上方後重新輸出完整成片。原句與例句均有中文。allocate 例句全展開約 6.1 秒，arbitrary 約 5.1 秒；英文主要 51–58px（手機 17–19px），中文 44–45px（手機約 15px）。分級與詞性為次要標示。

仍是無聲文字影片，沒有配音、音效或背景音樂。閱讀舒適度與「順便學會」的效果是設計判斷，未經真實觀眾測試；不把抽幀審查描述成人類實時完整觀看。來源正文一直保留，視窗邊緣容許下一段／上一段裁切；正文焦點與例句沒有裁切。自動 audit 僅查水平溢出，不能代替視覺檢查。

交付 `p2-v3.mp4`、HTML stills、成片抽幀 `mp4-stills/`、手機圖 `phone/`、`sheet-review.png`、`verification.json`。完成後停止，不批次套用。
